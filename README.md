# week2-2025-advanced-html-web-development-assignment

## 🎯 What Did I Build?
I created a webpage that showcases different HTML5 features! Think of it as building a digital house where every room has something special.

### 🏗️ The Building Blocks
1. **A List** - Using Roman numerals because regular numbers are too mainstream!
2. **Eye-Catching Image** - Borrowed (legally!) from Pexels
3. **Contact Directory** - Like your phone's contact list, but fancier
4. **Registration Form** - The smoothest signup experience you'll ever have!

## 🧠 What I Learned
- How to structure a webpage properly (it's like organizing your room, but digital!)
- Making lists count in Roman numerals (I, II, III... fancy, right?)
- Creating tables that actually make sense
- Building forms that:
  - Keep passwords secret (ninja style! 🥷)
  - Remember your birthday (so you don't have to!)
  - Give you cool options to choose from

## 🎮 Want to Try This Yourself?

### Tools You'll Need:
- VS Code (the Ferrari of text editors 🏎️)
- A web browser (any will do!)
- Your imagination (most important!)

### Steps:
1. Open VS Code
2. Create a new file called `index.html`
3. Copy the code (sharing is caring!)
4. Save and open in browser
5. Ta-da! You're now a web wizard! 🧙‍♂️
